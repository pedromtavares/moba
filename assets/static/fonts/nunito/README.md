# Nunito

Unmodified variable TrueType fonts from the official Google Fonts repository:

- `Nunito-Variable.ttf`: `ofl/nunito/Nunito[wght].ttf`
- `Nunito-Italic-Variable.ttf`: `ofl/nunito/Nunito-Italic[wght].ttf`
- `OFL.txt`: the accompanying SIL Open Font License 1.1

Source: https://github.com/google/fonts/tree/main/ofl/nunito

Copyright 2014 The Nunito Project Authors. Normal and italic faces cover weights
200–900. The application serves them locally with `font-display: swap`; no Adobe
subscription or hosted font service is needed.
