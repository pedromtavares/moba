# BrowserMOBA navigation artwork

Original raster emblems created with the built-in OpenAI image generation tool.
The approved Vanguard Helmet favicon established the shared art direction:
faceted antique gold, warm ivory, burgundy, and navy, with a transparent backdrop.

`profile.webp` uses that helmet; `arena.webp` uses the companion crossed-blades
concept. Base, Training, Tavern, Community, Manual, Admin, and Join were generated
as matching emblems. All application assets are exported at 256 × 256 in WebP
with alpha. The UI renders them at navigation size and applies the active glow.

See `prompts.json` for the generation brief and individual subjects. These assets
are local and do not depend on an icon font or a hosted icon service.
